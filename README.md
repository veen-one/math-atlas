# 数学知识地图 · Math Atlas

以 9 张知识地图为蓝本的交互式数学百科：从总览出发，进入 8 个学科，点击任意知识点，阅读定义、直觉、关键公式与例子。

## 打开方式

**方式一（推荐）**：在项目目录启动一个本地服务器：

```bash
cd "math-atlas" && python3 -m http.server 8765
```

然后浏览器访问 <http://localhost:8765>。

**方式二**：直接双击 `index.html`。页面为纯静态资源，无需构建；公式库优先使用本地 `vendor/katex/`，缺失时自动回退到 CDN。

## 交互

- **球形总览**：319 个知识点按 8 个学科分布在一个球面上，相关概念之间有连线；拖拽旋转、滚轮/双指缩放；悬停显示名称与简介，点击打开详解；点击学科名进入学科分支图
- **球体控制**：左下角可暂停/继续自转、只看收藏、重置视角
- **学科视图**：8 个分支放射展开，点击知识点打开右侧详情面板；悬停分支可高亮
- **搜索**：点击顶栏搜索框或按 `⌘K` / `/`，支持概念、分支与正文检索；在球体上搜索会直接定位并转到正面
- **快捷键**：`⌘K` 搜索、`R` 随机知识点、`←` / `→` 切换上一条/下一条、`Esc` 关闭
- **收藏与进度**：详解标题旁可收藏（持久保存），顶栏显示已读进度
- **公式**：每个公式卡片可一键复制 LaTeX 源码
- **路由**：`#/学科` 与 `#/学科/知识点` 可直接分享或收藏

## 内容结构

```
js/data/overview.js          总览（8 学科 + 48 个代表概念）
js/data/{subject}.js         各学科数据（分支、知识点、公式）
js/data/analysis-b.js        分析学科的补充分支（微积分 / 测度 / 泛函）
js/data/analysis-c.js        分析学科的补充分支（调和 / 微分方程 / 动力系统）
docs/content-spec.md         数据格式与写作规范
```

每个知识点包含：`definition`（定义）、`intuition`（直觉与动机）、`formulas`（KaTeX 公式）、`example`（例子）、`related`（相关概念）。

## 公式

公式由 [KaTeX](https://katex.org/) 渲染。若本地 `vendor/katex/` 不存在，页面会从 CDN 加载；离线且无本地库时，公式将显示为原始 LaTeX 源码（仍可阅读）。

## 深化学习内容

全部 319 个知识点在原有定义、直觉、公式和例子外，增加逐点编写的“适用条件与易错点”及“自测与推理”。解析默认折叠，便于先作答再核对；新增正文、补充例子和公式说明也参与搜索。

- `js/data/learning.js`：网站实际加载的 319 张深化卡片。
- `scripts/deepen-content.py`：逐点编写的原始内容及确定性生成脚本。修改后运行 `python3 scripts/deepen-content.py`。
- `node check.js`：按页面顺序执行全部数据，检查知识点、补充卡片、失效关联、控制字符和打包顺序。
- `python3 build_single.py --offline`：跳过外部样式下载，生成单文件页面；公式仍沿用 CDN 回退，完全断网时显示 LaTeX 源文。

本轮具体修改与验证见 `docs/content-upgrade.md`。


## 自包含证明扩写（进行中）

证明第一卷收录 404 个定理或命题，关联 319 个知识点。每个条目包含准确陈述、思路、逐步证明及前置依赖；页面可展开全部前置引理和基础定义。仓库其余定理尚未完成，不能把自测解析或特例视为全主题完整证明。

- `docs/proofs/volume-1.md`：可直接阅读的第一卷。
- `docs/proofs/volume-1.tex`：LaTeX 源码，使用 XeLaTeX 与 ctex、amsmath、amssymb、amsthm、hyperref、enumitem。
- `docs/proofs/coverage.md`：319 个知识点逐项状态。
- `docs/proofs/claim-audit.json`：候选定理句待核定清单；不是已穷尽或去重的全部定理。
- `python3 scripts/build-proofs.py`：生成证明数据与 Markdown / LaTeX。
- `node scripts/audit-proofs.js`：重新生成覆盖清单。

先运行两项生成命令，再运行 `python3 build_single.py --offline` 与 `node scripts/verify-content.js`。检查器会拒绝不存在的证明依赖和循环引用，但这不等于对数学正确性的形式验证。


证明续写源码按学科保存在 `scripts/proof-chapters/`，生成器按文件名顺序加载，所有命题仍进入同一依赖图。新增内容包括：有限域与伽罗瓦对应、有限维谱定理、实 Hilbert 空间投影、局部微分方程、复分析至代数基本定理、二次互反律、L² 概率与统计学习、紧致性和数值误差。具体版本条件均写在各命题陈述中；例如有限维谱分解不代替无限维谱定理，局部解不代替全局存在。
